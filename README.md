# Yolo Face Detection and Recognition with Enhanced Noise Reduction

This project combines a lightweight, adaptive noise‑estimation‑and‑denoising module specifically tuned for YOLO‑based face detection. Current solutions are either too slow, too static, or not evaluated in terms of detection metrics. Our project fills this gap by designing an efficient, frame‑adaptive preprocessing pipeline whose sole objective is to maximize face detection accuracy under noise while adding minimal latency.
